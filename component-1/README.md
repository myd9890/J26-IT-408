# Component 1 — Banana Disease Detection

## Objective

Develop an image-based banana disease detection system using few-shot learning and explainable AI (XAI).

## Initial Prototype

The progress prototype will focus on two banana diseases and a healthy class to demonstrate the complete end-to-end workflow.

## Architecture

Image Input
→ Image Preprocessing
→ Vision Feature Extraction
→ Few-Shot Classification
→ Disease Prediction
→ Explainable AI
→ Prediction + Explanation

## Deployment

The computationally intensive vision and AI models will be hosted in a cloud environment.

The Raspberry Pi 4 will act as an edge device for image acquisition, communication, and interaction with the cloud-based AI service.
